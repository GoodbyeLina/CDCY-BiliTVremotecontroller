首页（状态）

只做两件事：告诉你「现在是什么状态」，给你一个「开始 / 停止」。空闲和播放中是同一屏的两种状态，不跳页。

内容（源）

直播 / 列表一个开关切换。粘贴链接即时识别类型，识别结果直接显示「几个视频、叫什么」，避免填错还以为在播。

诊断（为什么）

播不出来时第一时间来这里。四项检查各自给结论和下一步动作，不放日志原文——日志在下一层。

设置（配置）

地址、端口这类改一次就忘的放这里；会跳系统页的（电池优化、自启动）给明确入口，不假装能自己改。

向导（第一次）

只在新装时出现。每步都能测、能返回，进度落配置里，中途退出下次接着走。

通知（常驻）

不是装饰：它是后台运行期间的「遥控器」，带停止和切下一个，不用回 App。
