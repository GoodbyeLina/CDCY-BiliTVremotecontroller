第 2 步 · 另一种情况

连不上电视

先别急，按顺序排一下

连接失败192.168.1.50:5555 无响应（超时 8 秒）

按这个顺序查

1
电视和手机是同一张 WiFi 吗
访客网络、双频合一有时会分到不同网段
2
电视上的「网络调试」还开着吗
部分电视重启后会自己关掉
3
IP 变了吗
路由器重启后电视可能换了地址
建议在路由器里给电视绑定一个固定 IP，以后就不会再遇到这个问题。
② 失败态
同一屏的异常分支：给原因 + 排查顺序，不给一串英文错误码
引导设计约定 后面写代码按这几条来，不临时发挥

每步只问一件事

网络、电视、播放器、内容、自检，五个独立问题。前一步没通过，后一步不展开——避免用户在前面填错、后面一路懵。

能测的必须能测

电视连接、播放器、B站、端口，每一步都给「测试 / 检测」按钮，结果当场显示，不靠用户自己判断。

中断可续

进度写进配置，退出 App 再进来从断点继续；已填过的字段带默认值，不要求重填。

失败给「怎么办」

错误信息必须是「原因 + 下一步动作」两段式；技术细节（超时秒数、异常类名）只进日志，不上屏。

不假装能自动

电视开调试、装播放器、点「允许调试」这些只能人做，就给清楚的图文指引，不做一个假装自动的等待动画。

只出现一次

向导只在新安装或用户主动「重新初始化」时出现；日常打开直接进首页，不重复打扰。

自动失败必须有退路

手机 IP 这类能自动探测的字段，一律同时允许手动填写；探测失败给出「去哪抄」的路径，而不是卡死在这一步。
