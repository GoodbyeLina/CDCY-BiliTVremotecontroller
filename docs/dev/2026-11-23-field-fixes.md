# alpha.5 现场反馈修复

版本：3.0.0-alpha.5 / versionCode 7 / 包名 tvrc.app。

## 现场反馈与修复机制

1. **直播未出现，反而播放随机音乐**：移除起播后最多三次全局 `KEYCODE_MEDIA_PLAY_PAUSE(85)` 补发。原实现只检查播放器进程，不判断是否暂停，全局媒体键可能暂停 mpv 或唤醒其他音乐应用。继续使用指定 mpv Activity 的 VIEW Intent，不改视频解析、快进快退、音量或遥控器按键。另修复 AppGraph 复用后新导入直播间没有加入代理允许列表的问题：在 Launch 前的 Starting 通知中同步会话与房间列表，无关房间仍返回 400。两处代码缺陷已修正，但不能据此断言现场随机音乐的唯一原因，仍需实机直播复测。
2. **视频能播但自检 ADB 超时、播放器未知**：同一电视目标已有服务传输层时，自检通过该层串行执行真实 echo 与应用列表查询，不再建立竞争连接、不关闭借用连接；没有服务传输层时仍独立连接。自检失败不再覆盖服务探针的在线/播放状态。保留 echo、应用查询各自失败语义；握手超时增加首包/签名/等待授权阶段提示，未放宽认证或伪造通过。
3. **删除旧链接并粘贴后仍导入旧链接**：EditText 文本变化立即同步草稿（包括空文本）；状态刷新不再重建正在编辑的导入框，保留系统粘贴目标、焦点与文本。
