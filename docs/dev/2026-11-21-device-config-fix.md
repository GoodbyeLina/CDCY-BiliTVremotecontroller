# 电视 IP 保存与输入保留修复（3.0.0-alpha.2）

## 现象和原因

首次安装后，在「设备」页填入电视 IP 并保存，出现 `source=live 时 rooms 不能为空`，关闭提示后 IP 被清空。诊断包中没有 config.json，播放日志仍提示电视地址为空。

设备页错误地复用了旧版播放配置校验。三代 App 从独立内容库选择播放目标，因此配置电视时无需先填旧配置中的 rooms。保存失败后页面无条件重建，又从尚未保存的旧配置回填输入。后台状态通知同样会触发全页重建，输入过程中也可能丢失内容或焦点。

## 修复

- 增加设备设置校验入口，保留 IP、端口、播放策略的校验，允许在空内容库状态下先保存设备。旧版播放配置与命令行校验继续要求播放内容。
- 保存失败时保留当前表单；磁盘写入失败显示错误而不更新内存配置。
- 后台状态通知仅更新设备页顶部状态，不重建设备表单。
- 用页面草稿保留未保存输入，覆盖切换页签和 Activity 重建。明确点击「重新加载」时才丢弃草稿并加载保存值。
- 修正自定义 ADB 端口序列化中的多余 `@`，确保保存后能读回端口。
- APK versionCode 升为 4，版本为 `3.0.0-alpha.2`；配置结构版本与 core API 版本保持 1。

## 回归检查


核心测试覆盖空内容库保存/重读、保留原播放校验、非法设置不覆盖旧文件、自定义端口往返。Android 界面测试使用 Robolectric，覆盖点击保存与重载、保存失败后修正、后台刷新时输入控件及焦点不变、切换页签和 Activity 重建后的草稿。

2026-11-21 本地验证：核心 189 项、Android 界面 5 项全部通过，无失败或跳过。界面测试使用 Android API 28 模拟环境，不代替用户 Android 16 手机与电视的真机联调。

## 真机复测

1. 覆盖安装 alpha.2，进入「设备」页填入电视的实际 IP，保存后重新加载，确认 IP 仍在。
2. 将代理端口改成 8099 并保存，确认报错后 IP 和端口输入仍在；改回 8100 后可保存。
3. 输入 IP 后等待一轮后台刷新、切换页签再返回，确认输入未丢失。
4. 保存后运行自检，确认「电视地址为空」不再出现；电视 ADB 连接、授权、播放器安装及实际播放仍需在真实局域网中验证。
