# 小白版：从零把「B站轮播台」装到旧手机上

> 这份是给**没用过 Termux、没写过 Linux 命令**的人看的。
> 你不需要懂编程，只要会“复制一行、粘贴、按回车”。
> 遇到 `$` 开头的行是 Termux 的提示符，**不要输入 `$` 本身**，只输入它后面的命令。

---

## 0. 开始前，先准备这些东西

- [ ] 一台 Android 7.0–11 的旧手机（你已确认）
- [ ] 手机能长期插电，WiFi 稳定
- [ ] 小米电视（Android，已装 mpv-android，已开网络调试）
- [ ] 手机和电视连同一个 WiFi
- [ ] 一台电脑（用来把压缩包传到手机）
- [ ] 路由器里给手机和电视做 DHCP 固定（强烈建议，不做也能先用）

> 电视端不用装新东西；只要确认 mpv-android 还在、网络调试还开着。

---

## 1. 手机装 Termux 和 Termux:Boot

> 不要用 Google Play 里的 Termux，用 F-Droid。

1. 手机浏览器打开：<https://f-droid.org/packages/com.termux/>
   点 **Download APK**，安装。
2. 再打开：<https://f-droid.org/packages/com.termux.boot/>
   点 **Download APK**，安装。
3. 装完**先点开一次 Termux:Boot 图标**，看到界面后可以直接关掉。
   这一步是告诉 Android：“开机时允许它运行”。

> Termux 和 Termux:Boot 必须来自同一个地方（都用 F-Droid）。如果混装，会提示签名不一致。

---

## 2. 认识 Termux：它其实就是一个“黑色的命令行”

打开 Termux，你会看到类似：

```
~ $
```

这就是等你输入命令的地方。你只需要记住 4 件事：

| 操作 | 怎么做 |
|---|---|
| 粘贴 | 在 Termux 里**长按屏幕** → Paste（粘贴） |
| 执行 | 粘贴完按键盘上的 **回车/Enter** |
| 取消当前命令 | 按 **Ctrl + C**（Termux 键盘上方有 Ctrl） |
| 放大字体 | 双指捏合/张开，或音量键 |

> 下面的命令都可以从这份文档里复制，粘贴到 Termux，按回车。

---

## 3. 装运行需要的软件

在 Termux 里粘贴这一整行，按回车：

```bash
pkg update -y && pkg upgrade -y
```

等它跑完（可能要几分钟，别关 Termux）。然后再粘贴这一行：

```bash
pkg install -y python android-tools termux-services iproute2 curl unzip
```

- `python`：跑主程序
- `android-tools`：就是 adb（控制电视用）
- `termux-services`：让程序崩溃后自动重启、开机自启
- `iproute2`：查手机 IP
- `curl`：测试网络
- `unzip`：解压

如果下载很慢/报镜像错误，先执行：

```bash
termux-change-repo
```

用方向键选一个国内镜像（清华/中科大/北外），回车确认，再重新执行上面的 `pkg update` 和 `pkg install`。

---

## 4. 把压缩包放到手机里

### 最简单：用微信/QQ 传给自己

1. 在电脑上把 `termux-port.zip` 发到“文件传输助手”/“我的电脑”。
2. 手机上打开微信/QQ，把文件**保存到手机**。
3. 用手机自带的“文件管理”App，把 `termux-port.zip` **移动/复制到 `Download`（下载）文件夹的根目录**。
   - 注意：不是 `Download/WeChat` 里面，而是 `Download` 这一层。
   - 如果文件名变成了 `termux-port(1).zip`，改回 `termux-port.zip`。

### 然后在 Termux 里执行

```bash
termux-setup-storage
```

手机会弹“允许 Termux 访问文件吗”，点**允许**。然后：

```bash
cd ~
unzip ~/storage/downloads/termux-port.zip
mv ~/termux-port ~/tvstation
cd ~/tvstation
ls
```

最后一行 `ls` 应该能看到：

```
README.md  install-termux.sh  mode.sh  set-content.sh  station.py  ...
```

> 如果 `unzip` 说找不到文件：在 Termux 里执行
> `find ~/storage -name "termux-port.zip"`，把显示的完整路径替换到 `unzip` 后面。
>
> 如果 `mv` 说 `~/tvstation` 已存在：说明之前装过，执行
> `rm -rf ~/tvstation` 再重新 `mv`（确认旧目录里没有你要保留的配置）。

---

## 5. 找到电视的 IP 地址

在电视上：

**设置 → 网络 → 有线/无线 → 当前网络 → IP 地址**

你会看到类似 `192.168.1.23`。记下来，后面填。

> 电视和手机必须在同一个 WiFi。手机用 5G 频段、电视用 2.4G 频段一般也可以，只要是同一个路由器、同一个网段。
>
> 如果路由器开了“AP 隔离/访客网络”，电视会连不到手机，必须在路由器里关掉。

---

## 6. 找到“直播间号”或“合集链接”

### 6.1 直播间号（live 模式）

直播间号不是 UP 主的名字，是**直播间地址里的那串数字**。

用 B 站 App：

1. 搜到那个 UP 主，进他的主页。
2. 点“直播”/“直播间”。
3. 右上角分享 → 复制链接。
4. 链接一般长这样：

```
https://live.bilibili.com/5017134?broadcast_type=0
```

`live.bilibili.com/` 后面的 `5017134` 就是直播间号。

> UP 主没开播时，直播间号也是固定的；开播时分享出来的链接里就是它。
>
> 你也可以在手机浏览器打开 `https://live.bilibili.com/`，搜 UP 名字，进直播间后看地址栏。

### 6.2 合集/列表链接（video 模式）

不是单个视频的 BV 号，是“合集/列表”的链接：

```
https://space.bilibili.com/23191782/lists/1424266
```

- `23191782` = UP 主的 mid
- `1424266` = 列表 id

在 B 站 App 里：UP 主页 → 合集/列表 → 分享 → 复制链接。

> 如果你只想播**一个视频**，当前这版不支持；它只轮播整个合集。要单视频得另外加功能。

## 7. 运行安装脚本

在 Termux 里：

```bash
cd ~/tvstation
bash install-termux.sh
```

它会依次问你。下面是一个例子（你的 IP 和房间号会不一样）：

```
== 1/7 电视 ==
  电视 ADB 地址（IP 或 IP:5555） [192.168.10.139:5555]: 192.168.1.23:5555

== 2/7 手机 WiFi 地址 ==
  手机 WiFi IP（电视要能访问它） [192.168.1.50]: 直接回车

== 3/7 轮播内容 ==
  默认模式 live=直播间轮播 / video=列表视频 [live]: 直接回车
  直播间号（英文逗号分隔） [5017134,...]: 5017134
  列表所属 UP 主 mid（video 模式用） [23191782]: 直接回车
  视频列表 id（video 模式用） [1424266]: 直接回车
```

要点：

- 方括号 `[...]` 里是默认值，**直接回车**就用它。
- 电视 IP 要填你自己的；如果只填 `192.168.1.23`，脚本会自动补 `:5555`。
- 手机 IP 一般自动探测对了，直接回车。
- 直播间号可以填多个，用英文逗号：`5017134,5064126`。
- 现在只填直播也行，合集那两个选项先回车用默认值，以后再用 `set-content.sh` 改。

### 电视上点“允许”

脚本跑到 `adb connect` 时，电视屏幕可能弹出：

> 允许 USB 调试吗？

勾选“一律允许”，点**允许**。

如果没弹窗，或者显示 `unauthorized`：

1. 电视：设置 → 开发者选项 → 确认“网络调试/USB 调试”是开的。
2. 有的电视还有“ADB 需要确认”，把它关掉。
3. 回到 Termux，重新执行 `bash install-termux.sh`（会保留/备份配置）。

## 8. 验证有没有成功

在 Termux 里：

```bash
cd ~/tvstation
./tvctl status
```

正常会看到类似：

```
== 服务 ==
run: tvstation: (pid 12345) 10s
run: tvcontrol: (pid 12346) 10s

== 8099 /api/status ==
[{"room": 5017134, "live": true, "title": "...", "online": 1234}]

== 最近日志 ==
...
```

电视应该在 10–15 秒内出画面。

- **单直播间模式**（App 里选一个台，`source=single`）：一直播这一个，不自动换台。
- **多直播间轮播**（`source=live`，`rooms` 里多个）：每 30 秒换一个在播的台。

如果 `[]`：等 10 秒再试；可能还没查到状态。
如果 `(代理无响应)`：`tail -n 50 station.log` 看报错。

## 9. 以后怎么换直播间/合集

不用手改 JSON，直接运行：

```bash
cd ~/tvstation
./set-content.sh
```

它会显示当前配置，然后让你选：

```
1) 直播间轮播
2) 合集/列表视频轮播
```

### 选 1：换直播间

把直播间链接或房间号粘贴进去：

```
https://live.bilibili.com/5017134
```

或者：

```
5017134,5064126
```

它会自动识别、写入、重启服务。

### 选 2：换合集

把合集链接粘贴进去：

```
https://space.bilibili.com/23191782/lists/1424266
```

或者分两次输入 `mid` 和 `列表 id`。

> 这版仍然**只认直播间号/链接和合集链接，不认 UP 名字**。
> 想“只输入 UP 名字”要用第 3 问里说的 App/搜索功能，需要另外做。

## 10. 开机自启

1. 确认 Termux:Boot 已经装好，并且**点开过一次**。
2. 确认 Termux 的电池优化已关闭、自启动权限已给（见 README 3.2 节）。
3. 重启手机。
4. **解锁一次**（如果有锁屏；Android 7+ 要等首次解锁才发开机广播）。
5. 不要打开 Termux，等 1–2 分钟。
6. 在电脑/另一台手机上打开：

```
http://手机IP:8099/api/status
```

有 JSON 返回就说明自启成功。

## 11. 手机 App / 网页控制台（可选）

装好后端后，手机上还有一个“遥控器”界面：

- 在手机浏览器打开：`http://127.0.0.1:8098`
- 或者安装现成的 APK：`TVStationRemote-0.2.0.apk`（在压缩包外面、和 `termux-port.zip` 同一目录）。

第一次打开 APK 会按顺序走 5 步，每步通过才能下一步：

1. 手机网络（自动读当前 WiFi IP）
2. 电视连接（扫描局域网 5555 / 手动 IP / 电视点允许）
3. 电视播放器（检查 mpv-android）
4. 选直播间（搜 UP / 粘链接，允许未开播）
5. 完成

以后打开时，如果全部正常就直接进主页；哪一步有问题，只弹那一项。  
设置里还有“修改”和“重新初始化”，换 WiFi/换电视时用。

完整的从零调试步骤（含兼容性检查、Termux 装什么、分层排查、配图）见：
[`../全流程调试手册.md`](../全流程调试手册.md)。

它可以：

- 搜 UP 名字（同名会列出来让你选）
- 粘贴直播间链接 / 纯数字直播间号
- 一键切换当前直播间（只播这一个，不自动轮换）
- 停止 / 唤醒电视 / 重启服务
- 看最近日志

如果 App 打开显示“控制服务没有启动”：

1. 打开 Termux；
2. 执行 `cd ~/tvstation && ./tvctl status`；
3. 确认能看到 `run: tvcontrol: ...`；
4. 回 App 点“重新连接”。

> App 只是遥控器，后台仍然是 Termux 在跑。不要 force-stop Termux。
> 控制台只监听 `127.0.0.1`，同一 WiFi 的别人打不开，这是故意的。

## 12. 常见问题（小白版）

| 你看到的 | 怎么办 |
|---|---|
| `bash: install-termux.sh: No such file` | 先 `cd ~/tvstation`，再 `ls` 看文件在不在 |
| `Permission denied` | 用 `bash install-termux.sh`，不要用 `./install-termux.sh` |
| `unzip: cannot find ...` | 用 `find ~/storage -name "termux-port.zip"` 找完整路径 |
| `sv: command not found` | `pkg install termux-services`，然后关掉 Termux 重开 |
| `adb: no devices/emulators found` | 电视没开网络调试，或没点“允许”；`adb connect 电视IP:5555` |
| `unauthorized` | 电视上点允许；或删手机密钥：`rm -rf ~/.android/adbkey*`，再 `adb connect` |
| `curl: (7) Failed to connect` | 服务没起来；`./tvctl status`、`tail -n 50 station.log` |
| 状态一直是 `[]` | 等 10 秒；或手机出不了网；`curl -s https://api.bilibili.com/x/web-interface/nav` 测试 |
| 电视黑屏，但日志有 `[调度]` | 电视侧问题：mpv 没装、`am start` 失败、屏幕没亮；`./tvctl wake` |
| 跑几小时就停 | Termux 被系统杀了；关电池优化、给自启动、最近任务锁定 |
| 重启后没自启 | Termux:Boot 没点开过 / 没解锁 / 电池优化没关 |
| 中文输入不了 | `set-content.sh` 只需要数字和链接，不需要打中文 |

## 13. 你只需要记住的 5 条命令

```bash
cd ~/tvstation          # 进入程序目录
./tvctl status          # 看状态
./set-content.sh        # 换直播间/合集
./tvctl restart         # 改完配置重启
tail -n 50 station.log  # 看最近日志
```

就这些。剩下的都是复制粘贴。
